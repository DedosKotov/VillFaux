# VillFaux

**VillFaux** — экспериментальный плагин для Paper. Он добавляет редкого жителя с необычной торговлей и опасными последствиями.

Проект находится в разработке. Возможны ошибки, изменения механик и несовместимость с будущими версиями Paper.

## Возможности

- Редкий житель **VillFaux** может появиться в мире с очень небольшим шансом.
- После появления игрокам отправляется сообщение с координатами.
- VillFaux предлагает выгодную сделку: **1 блок земли → 1 обычное золотое яблоко**.
- После успешной сделки может произойти одно случайное последствие:
  - взрыв мощностью 7;
  - появление тыквы;
  - две самонаводящиеся визуальные стрелы;
  - отсутствие последствий.
- После смерти VillFaux или поборника происходит взрыв.

## Важно

- Плагин является экспериментальным.
- Взрывы могут разрушать постройки.
- Перед использованием на сервере сделайте резервную копию мира.
- Механики и настройки могут изменяться.

## Сборка

Нужны установленные Java и Maven.

В папке проекта выполните:

```bash
mvn clean package
```

Готовый плагин появится здесь:

```text
target/VillFaux-1.0.0.jar
```

## Установка

1. Поместите `VillFaux-1.0.0.jar` в папку `plugins` сервера Paper.
2. Запустите сервер.
3. Настройте файл `plugins/VillFaux/config.yml`.
4. Перезапустите сервер.
